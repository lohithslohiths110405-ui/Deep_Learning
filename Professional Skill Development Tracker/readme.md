# Professional Skill Development Tracker

## Deep Learning, Models and Applications

This repository contains my **Professional Skill Development Tasks** in Deep Learning.

The project includes **15 tasks** covering neural networks, CNNs, LSTMs, optimization, Transformers, GANs, anomaly detection, CUDA, and distributed training.

## Tasks

### Task 1 – Multi-Layer Perceptron

* Implement MLP from scratch.
* Learn forward propagation and backpropagation.
* Tools: Python, NumPy, Jupyter Notebook.

### Task 2 – Weight Initialization

* Study Xavier and Kaiming initialization.
* Analyze vanishing and exploding gradients.
* Tools: PyTorch, NumPy, Matplotlib.

### Task 3 – Convolution using im2col

* Implement convolution from scratch.
* Understand padding, stride, and channels.
* Tools: NumPy, SciPy.

### Task 4 – Optimizers

* Implement Momentum, RMSprop, and Adam.
* Study optimization and loss convergence.
* Tools: PyTorch, NumPy.

### Task 5 – Batch & Layer Normalization

* Implement Batch Normalization and Layer Normalization.
* Understand normalization and gradients.
* Tools: PyTorch, NumPy.

### Task 6 – BiLSTM

* Implement a Bidirectional LSTM.
* Understand gates and cell states.
* Tools: PyTorch, NumPy.

### Task 7 – ResNet Block

* Implement a ResNet-style bottleneck block.
* Study residual and grouped convolutions.
* Tools: PyTorch, TorchVision.

### Task 8 – Semantic Segmentation

* Build a U-Net segmentation model.
* Implement Dice Loss and Binary Cross-Entropy.
* Tools: PyTorch, TorchVision, Albumentations.

### Task 9 – Object Detection

* Implement YOLOv8-style loss components.
* Study bounding box regression and classification.
* Tools: PyTorch, OpenCV, NumPy.

### Task 10 – WGAN-GP

* Build a Wasserstein GAN with Gradient Penalty.
* Study stable image generation.
* Tools: PyTorch, TorchVision.

### Task 11 – Vision Transformer

* Implement image patch projection.
* Implement multi-head self-attention.
* Tools: PyTorch, Einops, Transformers.

### Task 12 – Autoencoder

* Build a Convolutional Autoencoder.
* Detect anomalies using reconstruction error.
* Tools: PyTorch, SciPy, Scikit-learn.

### Task 13 – Temporal Convolutional Network

* Build a TCN for time-series data.
* Study dilated causal convolutions.
* Tools: PyTorch, Pandas, NumPy.

### Task 14 – CUDA Swish Activation

* Implement a custom Swish activation using CUDA.
* Compare GPU performance.
* Tools: C++, CUDA, PyTorch.

### Task 15 – Distributed Training

* Implement multi-GPU distributed training.
* Use PyTorch DDP with GLOO/NCCL.
* Tools: PyTorch Distributed, Docker, NCCL.
